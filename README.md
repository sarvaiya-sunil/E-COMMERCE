# 🛒 MERN E-Commerce Store

A full-stack E-Commerce web application built using the **MERN Stack**. It provides a seamless shopping experience with secure authentication, product management, shopping cart functionality, Stripe payment integration, coupon support, and an admin dashboard for managing products and viewing sales analytics.

## 🌐 Live Demo

🚀 **Try the application here:** https://e-commerce-1-idjw.onrender.com/

> **Note:** This application is hosted on Render's free tier. If the application has been inactive, the first request may take **30–60 seconds** while the server wakes up.

## 🚀 Features

### 👤 User Features

- User Authentication (Signup/Login)
- Browse Products by Category
- Featured Products
- Product Recommendations
- Shopping Cart Management
- Apply Discount Coupons
- Secure Stripe Checkout
- Order Placement

### 👨‍💼 Admin Features

- Add New Products
- Delete Products

## 📖 Project Description

This project is a full-stack **MERN E-Commerce Store** developed to simulate a real-world online shopping platform. It includes secure user authentication, product browsing by category, shopping cart management, coupon support, Stripe payment integration, and an admin dashboard for managing products and monitoring sales analytics. The application is built with a modern and responsive user interface using React, Tailwind CSS, Framer Motion, and Zustand, while the backend leverages Node.js, Express.js, MongoDB, Redis, Cloudinary, and Stripe to provide a scalable and efficient shopping experience.
